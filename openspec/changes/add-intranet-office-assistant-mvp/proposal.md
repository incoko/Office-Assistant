## Why

单位办公电脑无法访问互联网，非技术同事需要一款连接内网私有化模型、能够直接处理授权办公材料的 Windows 助手，而不是需要自行安装开发环境的工具集合。第一版以模拟材料验证三个常用场景，同时建立可配置智能体、Skill 和 MCP 的通用框架，避免后续扩展时重做应用。

## What Changes

- 新建独立 Windows 桌面客户端，以任务对话为中心，提供文稿整理、固定模板 Excel 汇总检查、制度查询三个快捷入口。
- 支持预配置开箱使用和高级配置两种方式；高级设置可管理模型连接、智能体、技能及工具，但不等于组织级管理员权限。
- 接入已确认采用 vLLM 部署的 Qwen3.6，优先适配内网 OpenAI 兼容 Chat Completions 接口；实际模型标识、流式和工具调用能力通过接口测试核实，不以提供启动命令为前提。允许向获准的内网服务发送任务必需数据，禁止访问外网及未经授权的服务；不集成外部遥测、更新和资源下载。
- 建立统一任务运行时，支持状态展示、工具执行记录、权限确认、取消、失败提示和本地产物管理。
- 支持本地导入 Skill、依赖检查及按智能体启停；第一版优先兼容现有 HTTP＋SSE MCP 服务，Streamable HTTP 仅预留扩展。智能体配置 MCP 后由客户端自动获取工具清单和参数模式，不要求预先提供清单或为 `pg-mcp` 编写专用逻辑；工具发现不等于执行授权。
- 默认只读取用户授权的文件，在指定输出目录新建文件，不覆盖或删除源文件。仅支持受控的预置执行工具，不运行任意导入脚本。
- 提供离线安装和不含密钥的配置分发方式，任务记录与配置存放本机，不建设团队后台。
- 以 `samples/` 的虚构材料作为功能验收基线，并验证自定义智能体、Skill 导入和内网 MCP 接入的真实可用性。

## Capabilities

### New Capabilities

- `desktop-workbench`: 非技术用户工作台、离线部署、本地任务记录与产物访问。
- `agent-runtime`: 可配置智能体、内网模型适配、统一任务生命周期与工具执行。
- `intranet-security`: 内网访问边界、凭据保护、文件授权、执行限制与审计记录。
- `extension-management`: 本地 Skill 管理、内网远程 MCP 接入及配置导入导出。
- `document-drafting`: 基于原始记录生成周报、会议纪要及 Word 草稿。
- `spreadsheet-checking`: 固定模板 Excel 合并、确定性检查和来源定位。
- `policy-retrieval`: 小规模本地制度检索、原文引用、版本展示及无依据拒答。

### Modified Capabilities

无。当前无已有能力规格或应用实现。

## Impact

- 新增桌面界面、任务运行时、模型适配、权限策略、本地存储、文档处理和扩展模块；技术栈不在本提案中提前锁定。
- 目标试点环境已确认：Windows 10 x64、8GB 内存，安装软件时可由管理员运行安装程序并安装到 `D:\Program Files\Office Assistant\`；普通用户可以日常启动客户端。当前不把应用白名单、内网证书要求、脚本和子进程限制列为本次开发与部署测试的额外前置条件。模型接口、必要认证信息、批准的服务地址、网络策略和服务端数据处理约定，统一在功能开发完成后的内网部署测试阶段确认。现有 MCP 配置为 SSE 与内网 HTTP；HTTP 仅经部署策略对特定目标显式放行，包含 SSE 动态消息提交端点检查。启动命令和预先整理的 MCP 工具清单不列为开发前置条件。
- 通过 CPython 3.12 x64、PyInstaller onedir 和 Inno Setup 6.3+ 形成 Windows 离线打包链；安装包包含 Python/Tk 运行时和预置资源，普通用户无需联网安装依赖或编辑 JSON；模型和可选 MCP 服务由内网环境提供，不随客户端部署服务器。
- 新增文档与扩展兼容性测试、安全负向测试及单位 Windows 环境离线验收；开发机验证不能替代目标环境验收。
- 本变更仅定义模拟材料试点，不授权真实银行数据处理，不代表已获得单位软件安装或业务使用许可。

## Non-goals

- 不做桌面鼠标键盘自动化、自动发邮件、OA 提交、交易操作、授信判断或监管报送。
- 不做组织账号、团队后台、共享会话、多智能体协作或技能市场。
- 不做任意 Excel 理解、扫描件 OCR、录音转写或全行知识平台。
- 不做本地模型部署、任意代码执行、通用脚本沙箱或任意第三方扩展兼容。
- 本地 MCP 进程仅保留适配边界，不列入第一版必需验收。
