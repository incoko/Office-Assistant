# 办公助手演示材料

> 全部内容均为虚构，仅供产品测试。不代表任何银行真实制度、监管要求或业务数据，不得用于真实业务办理、合规判断或记录销毁决策。

本目录只包含样例文档与测试说明，不包含应用实现。样例时间为2026年9月，使用时不要自动理解为“本周”。

## 01 文稿整理

- `工作周报模板.docx`、`会议纪要模板.docx`：输出结构与生成约束。
- `原始工作记录.txt`：可直接提交给助手的虚构输入。
- 周报测试问题：请按模板生成2026-09-14至2026-09-18的周报。
- 纪要测试问题：请仅根据2026-09-16的会议记录生成会议纪要。

### 预期检查点

- 本周完成两次走访、两份问题清单、培训讲义更新以及报名表收集。
- 12人是报名人数，不能表述为已完成培训人数；没有数据支撑的完成率不得生成。
- 整改进展汇总截止日为2026-09-25，负责人必须标为待补充。
- 下周开展培训只是建议，不得写成会议已决定的安排。
- 会议纪要不把9月18日“报名表已收齐”的会后信息写成9月16日已知事实。
- 培训具体日期、场地及部分责任人缺失，应提示确认。

## 02 表格汇总

- `培训事项台账-空白模板.xlsx`：表头与检查规则。
- `演示东网点.xlsx`、`演示西网点.xlsx`：同模板样例，每份3行数据。
- 每份文件都有“事项台账”和“使用说明”两个工作表；只合并前者，保留来源信息。
- 测试问题：合并两份网点台账，按使用说明检查，生成问题清单，不修正或覆盖原文件。

### 故意放入的4个问题

| 问题 | 文件与位置 | 预期结果 |
|---|---|---|
| 缺少负责人 | 演示东网点.xlsx / 事项台账 / D3 | 报必填缺失 |
| 事项编号跨文件重复 | 东网点A4与西网点A3均为DEMO-003 | 同时定位两行；不要自动去重 |
| 无效日期 | 演示西网点.xlsx / 事项台账 / E4 = 2026-09-31 | 报日历日期无效 |
| 人数不平 | 演示西网点.xlsx / 事项台账 / G4:I4 = 10、6、5 | 报10不等于6+5 |

合并结果应保留6行。原始应完成人次合计55、已完成人次41、未完成人次15；这些仅为待核验原始合计，存在重复及人数错误，不能视为有效业务汇总或去重员工人数。重复编号算1组问题、影响2行；不要因报告呈现方式不同误判数量。

## 03 制度查询

- `模拟培训归档制度.docx`：用于上传、解析和引用测试。
- `模拟培训归档制度.md`：同内容的可读文本版本，便于审阅。
- 导入知识库时二选一，不要把两个格式当成两份不同制度。
- 回答应引用文件名、版本和条号，不强制依赖可能随排版变化的页码。

### 测试问题与预期依据

| 问题 | 预期答案要点 | 依据 |
|---|---|---|
| 培训前需要谁审核？ | 部门负责人审核培训计划 | 第二、三条 |
| 报名12人能否记为完成12人？ | 不能，需要签到记录和实际完成情况 | 第四条 |
| 培训归档需要哪些材料？ | 培训计划、讲义、签到记录、完成情况台账；未完成时还需说明 | 第五条 |
| 培训结束后多久提交归档？ | 3个工作日内提交，由部门负责人复核，再交资料管理员 | 第六条 |
| 归档资料保留多久？ | 本虚构制度设为归档登记日起1年；明确仅供测试 | 第七条 |
| 培训费用每人可以报销多少？ | 文件未规定，不能编造金额 | 第九条 |
| 客户交易记录保存多久？ | 超出文档范围，未找到依据 | 第一、九条 |
| 周五培训结束，下周几交？ | 说明3个工作日期限，并请求适用日历，不直接确定日期 | 第六、十条 |

## 使用边界

这套材料可用于界面原型、文件处理和结果验收讨论，不代表应用能力已实现。制度答案仅对该虚构文档成立，不能推广为任何银行的真实规定。首轮无需连接真实业务系统或远程MCP。
